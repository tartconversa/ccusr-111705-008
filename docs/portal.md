# 本地来源行为

非遗联名目录列出稳定的 `data-key` 和详情路径；详情需由浏览器导航读取，`商品规格`选择改变当前页面状态，`图片轮播`和`授权详情`是分步出现的可见内容。轮播素材会延迟加载且授权说明可能撤回。详情接口是浏览器页面，不是业务 API；运行时只允许访问环回来源。

`fixtures/portal.json` 提供合成业务资料，不包含真实个人数据。`records.save_catalog` 覆盖同一目录身份；`records.save_detail_entries` 以业务键追加入口访问，不把入口访问等同于资格、授权、可预约或正式提交。测试均只访问本地环回页面。

详情采集按 `商品规格` 当前选择记录 `#variant`、素材版本（`data-revision`）与来源地址；`图片轮播` 懒加载失败或素材被清空只记缺口；`授权详情` 链接缺失视为撤回，指向环回以外地址视为非授权站点且不跟随跳转，授权页与所选规格版本不一致也记缺口。素材与授权按 `商品:规格:r版本` 归键，不同规格或不同发布时刻的记录各自追加保存，不合并为一款商品。演练情形包括：规格已可选但素材与授权未上线（ip-03 典藏款）、授权链接指向非授权站点（ip-04）、授权已撤回（ip-05）。
